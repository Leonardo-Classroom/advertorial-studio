{% comment %} The source-file picker, shared by the portal and staff upload pages. The native control is kept — it is what actually carries the files to the server — but moved off screen and driven by a button, because its rendering is the browser's and cannot be styled, and because it gives no way to drop one file from a selection: picking again replaces the whole `FileList`. Removing a file works by rebuilding a `DataTransfer` and assigning its `.files` back to the input. That is the only writable path to a `FileList`; it is what makes the ✕ on each row possible at all. `required` is deliberately absent. On a control that is `display:none`, Chrome refuses to submit *and* cannot focus the field to explain why — the form simply appears dead. The check lives in the script below instead, and the server rejects an empty batch regardless (`upload.create_brief`). {% endcomment %}
