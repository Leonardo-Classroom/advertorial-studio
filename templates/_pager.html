{% comment %} Numbered pager, shared by the project and draft lists. The view supplies `page`, `page_range` (from `get_elided_page_range`, which the template cannot call because it takes an argument) and `pager_qs` — every other query parameter, already encoded, so paging keeps the sort and filters it was reached with. `core.pagination.paginate` builds all three. The range elides rather than listing every page: at 3-per-page a few hundred drafts is a hundred-odd numbers, which is a worse way to find page 40 than typing it into the URL.
