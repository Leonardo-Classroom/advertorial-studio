{% comment %} One online-endpoint list. Included twice — once for text, once for pictures — with `use` ("text"/"vision"), `rows`, and `selected_id`. Two lists rather than one shared list with two selection columns: the same endpoint rarely serves both (a model that writes well may not accept an image at all), and a shared list could not express that. The cost is retyping a key when one provider genuinely does both. Field names carry the use, so the two lists cannot collide in the POST: `provider_text_kind_0` vs `provider_vision_kind_0`. {% endcomment %}
